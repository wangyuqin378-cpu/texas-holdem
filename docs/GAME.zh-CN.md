# 德州扑克 · 多人网页实验

[English](../README.md)

**当前阶段：** 可本地启动的网页游戏原型，支持房间与机器人。完整多人流程、牌局边界和生产可靠性尚未全面验证；仅使用虚拟筹码，不含真实资金支付。

一个支持最多 **7 人** 同时在线游玩的德州扑克游戏。

## 功能特性

- 支持 2-7 人同时在线游戏
- 实时 WebSocket 通信
- 房间系统（创建/加入/快速匹配）
- 已实现的德州扑克流程
  - 盲注系统
  - 四轮下注（翻牌前、翻牌、转牌、河牌）
  - 手牌评估与比较
  - 弃牌 / 过牌 / 跟注 / 加注 / 全下
- 游戏内聊天
- 自动补充筹码

## 快速开始

### 1. 安装依赖

```bash
cd texas-holdem
npm install
```

### 2. 启动服务器

```bash
npm start
```

### 3. 打开浏览器

访问 `http://localhost:3000`

### 4. 邀请好友

- 分享房间号给好友，让他们输入房间号加入
- 或者在同一局域网内访问你的 IP 地址 + 端口号（如 `http://192.168.x.x:3000`）

## 游戏规则

1. 每位玩家初始获得 **1000** 筹码
2. 小盲注 **10**，大盲注 **20**
3. 每位玩家发 2 张手牌（底牌）
4. 公共牌分三轮发出：翻牌（3张）、转牌（1张）、河牌（1张）
5. 用手中 2 张底牌 + 5 张公共牌中选出最佳 5 张组合
6. 牌型大小：皇家同花顺 > 同花顺 > 四条 > 葫芦 > 同花 > 顺子 > 三条 > 两对 > 一对 > 高牌

## 技术栈

- **后端**: Node.js + Express + Socket.IO
- **前端**: 原生 HTML/CSS/JS
- **通信**: WebSocket (Socket.IO)
