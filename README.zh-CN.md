# 德州扑克 · 朋友局网页

[English](README.md)

为朋友一起玩牌或单人搭配机器人练习而做的浏览器牌桌，最多 7 人，仅使用虚拟筹码，不含真实资金支付。

创建房间后分享六位房间号；也可添加机器人直接开始。每场 20 手，初始筹码 1000，盲注 10/20。每手比牌结果完整保留，由真人确认后继续。

**当前状态：** 修复版已通过本地规则、真实 Socket.IO 联机及浏览器回归，包括完整 20 手到重新开局。生产发布、手机真机兼容和实际娱乐体验仍须分别验收，详见[验证记录](docs/VERIFICATION.md)。

## 开始使用

需要 Node.js 18+，CI 使用 Node.js 22。

```sh
git clone https://github.com/wangyuqin378-cpu/texas-holdem.git
cd texas-holdem
npm ci
npm start
```

打开 [localhost:3000](http://localhost:3000)，输入昵称并创建房间。朋友通过房间号加入；房主可选择机器人难度、风格。所有参与的真人点击“准备”后开局。

同一可信局域网可用电脑的局域网 IP 和端口访问；端口占用时用 `PORT=3001 npm start`。[线上网址](https://texas-holdem-production.up.railway.app/)在修复 PR 发布前仍可能是旧版本。

## 修复与玩法

- 修复弃牌或全下后无限过牌、不翻牌，以及终局重复派奖、非法加注和第 20 手总结错误。
- 比牌区展示全部参与者底牌、最佳五张、牌型与分池结果；已弃牌对手继续隐藏，全部对手弃牌时不强制亮牌。
- 刷新/断线通过会话凭证恢复座位，保留 5 分钟；同昵称不能接管别人，重复或过期操作不会再次生效。
- 机器人结合胜率、公开下注推断的持牌范围、位置、底池赔率和本场观察记录。默认标准难度，可选轻松/挑战，以及稳健/均衡/积极风格；无需模型 API，不宣称 GTO。
- 手机竖屏和横屏分别安排牌桌与操作区，聊天可折叠，结果与确认按钮互不遮挡。

## 游戏规则

最多 7 人、20 手、初始 1000、盲注 10/20；操作上限 120 秒。超时能过牌则过牌，否则弃牌。筹码用尽可在手间重购，盈利按累计买入计算。完整规则、边池、断线与离席处理见[规则说明](docs/RULES.md)。
